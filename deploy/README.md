# Deploying magzest.tech to the Hostinger VPS

> **Static hosting (no VPS yet):** upload the built pages, `css/`, `js/`, `assets/` **and `.htaccess`** to `public_html`. `.htaccess` sends the security headers (Content-Security-Policy, HSTS, clickjacking and MIME-sniffing protection) and is regenerated by `.\build.ps1`. If `public_html` already has a `.htaccess`, paste the `# BEGIN Magzest security headers` block into it instead of replacing the file. After uploading, check the site and the chat widget, and look for red CSP errors in the browser console (F12).

## 1. Make the bundle (on your PC)

```powershell
.\build.ps1
python deploy\make_bundle.py        # creates dist\magzest-deploy-<date>.zip
```

## 2. Upload it and run the setup script

Your VPS IP address and root password are in **hPanel → VPS → Overview**. The VPS should run Ubuntu 22.04 or 24.04.

```powershell
scp "dist\magzest-deploy-<date>.zip" root@<VPS-IP>:/root/
ssh root@<VPS-IP>
```

On the VPS (over SSH, or in hPanel's **Browser terminal**):

```bash
apt-get install -y unzip
unzip -o magzest-deploy-*.zip
bash magzest/deploy/setup-vps.sh
```

The script asks for the admin email and password. It then installs Node.js and Nginx, sets the site up as a service that restarts on its own, and prints the address to open. Check that the site loads at `http://<VPS-IP>`.

If hPanel's VPS **Firewall** is switched on, allow ports **80** and **443**.

## 3. Point the domain at the VPS

In **hPanel → Domains → magzest.tech → DNS records**. If the domain is linked to a Hostinger website with the CDN on, turn the CDN off for that site first, or the records below can't be changed.

| Type | Name | Change to |
| --- | --- | --- |
| A | `@` | `<VPS-IP>` (keep only one `@` A record) |
| AAAA | `@` | delete these (they point to the old hosting) |
| CNAME | `www` | delete it, then add **A `www` → `<VPS-IP>`** |

**Don't touch the MX, TXT or `autodiscover` records.** They run your Microsoft 365 email.

## 4. Switch on HTTPS

Once the domain points at the VPS (usually 5–60 minutes; you can check at dnschecker.org), run the script again:

```bash
bash magzest/deploy/setup-vps.sh
```

It finds that the domain now points at the server, installs a free Let's Encrypt certificate (which renews automatically), and redirects all traffic to HTTPS. The admin is at **https://www.magzest.tech/adminn/**. Logging in only works over HTTPS.

## Updating the site later

Repeat steps 1 and 2: build, bundle, upload, then `unzip -o` and run the script. Your settings, database, uploads and HTTPS are kept. If the new version fails to start, the script automatically rolls back to the previous one.

## Useful commands on the VPS

| What | Command |
| --- | --- |
| Live logs | `journalctl -u magzest -f` |
| Restart | `systemctl restart magzest` |
| Edit settings (SMTP, API key…) | `nano /etc/magzest/magzest.env`, then restart |
| Reset the admin password | `cd /opt/magzest/app/server && sudo -u magzest env $(grep -v '^#' /etc/magzest/magzest.env \| xargs) node scripts/create-admin.js you@magzest.tech "new password"` |
| Database, uploads, backups | `/var/lib/magzest` |
